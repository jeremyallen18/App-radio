# Definición del proyecto

## B) Nombre del proyecto

**Doliv Manager**: Desarrollo de un sistema móvil para la gestión de contenido y administración interna de Radio Doliv.

## C) Delimitación

- **Espacial**: el proyecto se desarrollará para Radio Doliv, mediante trabajo presencial durante la residencia profesional.
- **Temporal**: el desarrollo del proyecto tendrá una duración aproximada de 5 meses, comprendiendo las etapas de análisis, diseño, desarrollo, pruebas e implementación de la aplicación.
- **Demográfico**: el proyecto está dirigido a los administradores, responsables de área y empleados de Radio Doliv, quienes utilizarán la plataforma para administrar información, tareas y publicaciones.

## D) Objetivos

**General**

Desarrollar un sistema de gestión de contenido para Radio Doliv, conformado por una aplicación móvil, un backend y la integración con el sitio web institucional, que permita administrar información, tareas y publicaciones de manera centralizada.

**Específicos**

- Diseñar una interfaz móvil intuitiva para administradores y empleados.
- Desarrollar un backend basado en una API que permita la gestión centralizada de la información.
- Implementar una base de datos estructurada para el almacenamiento seguro de la información.
- Integrar la aplicación móvil con el sitio web oficial para administrar y actualizar el contenido publicado.
- Implementar mecanismos básicos de autenticación y control de acceso para proteger la información del sistema.

## E) Justificación

Radio Doliv carece actualmente de una plataforma centralizada para administrar su contenido, comunicarse con su personal y organizar sus actividades internas, lo que provoca duplicidad de esfuerzos y pérdida de información. Por ello se desarrollará una aplicación móvil que permita a los administradores y empleados gestionar contenido, tareas y publicaciones desde un mismo lugar, agilizando la comunicación interna y la organización del trabajo.

Esta solución es importante porque optimiza el tiempo del personal, reduce errores por falta de información centralizada y sienta las bases técnicas para la difusión de contenido hacia el público, incluyendo la posibilidad, solicitada expresamente por el propietario de Radio Doliv, de actualizar desde la aplicación el contenido del sitio web oficial de la radio.

En términos económicos reduce costos operativos al evitar el uso de múltiples herramientas dispersas, en lo social mejora la comunicación entre el equipo de trabajo, y en lo técnico se apoya en una base de datos estructurada que facilita el mantenimiento y crecimiento futuro del sistema.

El proyecto también busca modernizar la arquitectura tecnológica del sistema utilizado por Radio Doliv, centralizando la administración del contenido mediante un backend que permita la integración entre la aplicación móvil y el sitio web institucional, facilitando el mantenimiento, la escalabilidad y futuras ampliaciones del sistema.
