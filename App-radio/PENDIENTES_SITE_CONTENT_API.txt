---------------------------------------------------------------------
Seguir la seccion "Despliegue" de docs/site-content-api.md:
  [ ] Aplicar migrations/036_site_content_audit_log.sql ANTES de subir el PHP.

      (generar con: php -r "echo bin2hex(random_bytes(24)).PHP_EOL;")

      (si el servidor corta antes, PHP vacia $_POST y sale un error confuso
      tipo "title es requerido" en vez de un mensaje de tamano)
  [ ] Revisar datos legado en la BD de PRODUCCION antes de subir el codigo.
      Ahora son estrictas (http/https obligatorio, sin comillas ni espacios)
      estas columnas; solo 2 de 7 se verificaron antes de hacerlas estrictas.
      En local estan limpias, pero produccion puede tener filas viejas que
      bloquearian editar ese registro desde la app:
        - anuncios.link_web / link_facebook / link_whatsapp
        - radio_services.whatsapp_url
        - team_socials.url
        - sponsor_socials.url
        - sponsors.map
      Tambien: sponsors.category / category_label y radio_services.category
      ya no pueden ir vacios.
      SELECT sugerido (correr en produccion, solo lectura):
        SELECT 'anuncios' t, id, link_web v FROM anuncios WHERE link_web <> '' AND link_web NOT LIKE 'http%'
        UNION ALL SELECT 'anuncios', id, link_facebook FROM anuncios WHERE link_facebook <> '' AND link_facebook NOT LIKE 'http%'
        UNION ALL SELECT 'anuncios', id, link_whatsapp FROM anuncios WHERE link_whatsapp <> '' AND link_whatsapp NOT LIKE 'http%'
        UNION ALL SELECT 'radio_services', id, whatsapp_url FROM radio_services WHERE whatsapp_url <> '' AND whatsapp_url NOT LIKE 'http%'
        UNION ALL SELECT 'team_socials', id, url FROM team_socials WHERE url NOT LIKE 'http%'
        UNION ALL SELECT 'sponsor_socials', id, url FROM sponsor_socials WHERE url NOT LIKE 'http%'
        UNION ALL SELECT 'sponsors.map', id, map FROM sponsors WHERE map <> '' AND map NOT LIKE 'http%'
        UNION ALL SELECT 'sponsors.cat', id, category FROM sponsors WHERE category = '' OR category_label = ''
        UNION ALL SELECT 'radio_services.cat', id, category FROM radio_services WHERE category IS NULL OR category = '';
      Si devuelve filas: corregirlas a mano antes del despliegue.
